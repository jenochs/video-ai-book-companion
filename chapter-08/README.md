# Chapter 8 - From Models to Systems

Capstone: expose LTX-2.3's audio-to-video pipeline (`a2vid_two_stage` in
`ltx_pipelines`) as a user-accessible feature across three platforms.

## Contents

- `src/`: the extension implementation for each platform
- `notebooks/`: walkthrough notebooks
- `assets/`: configs and sample inputs

## Platforms covered

| Platform    | Extension style             |
|-------------|-----------------------------|
| LTX Desktop | Vendor-controlled extension |
| Invoke AI   | Typed invocations           |
| ComfyUI     | Duck-typed nodes            |
